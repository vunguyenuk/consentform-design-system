# Fonts used by ENT Senior Care

Updated 13 October 2026.

| Family | Weights | Usage |
| --- | --- | --- |
| Inter | Regular 400, Medium 500, SemiBold 600 | V1 and V2 headings, body, controls and tables |
| Manrope | ExtraBold 800 | V1 wordmark |

TTF files are from the Google Fonts stylesheet referenced by index.html. The families retain their original font metadata. fonts.css provides local font-face declarations; manifest.json records official source URLs and SHA-256 hashes. System sans-serif and monospace fallbacks, plus the document/signature Georgia style, are not bundled fonts.
